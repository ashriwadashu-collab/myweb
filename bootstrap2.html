Web Technologies

HTML

HTML stands for HyperText Markup Language. It is used to create the structure of a website.

CSS

CSS is used to style websites with colors, layouts, spacing, fonts and responsive designs.

JavaScript

JavaScript makes websites interactive. It is used for events, animations, sliders and APIs.

jQuery

jQuery is a JavaScript library that makes DOM manipulation and animations easier.

Bootstrap

Bootstrap is a CSS framework used to create responsive and mobile-friendly websites quickly.
